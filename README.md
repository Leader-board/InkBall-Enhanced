## InkBall Enhanced

This is a ChatGPT-based rewrite of the classic Windows Vista game Inkball, with some additional features. 

> [!WARNING]
> I have not reviewed the code for the most part, and the code I did review isnt necessarily how I would write it either. This project is mainly a proof-of-concept - fixes welcome. 

## Why?

With the exception of https://github.com/TC999/inkballd, I have not seen any attempt of updating Inkball for modern Windows systems, unlike the venerable [3D Space Cadet](https://github.com/k4zmu2a/spacecadetpinball). The ones I could find were nowhere close to the one shipped with Windows, which I think is a shame. Additionally I was looking to get some useful statistics on the current run. Hence this port. 

> [!NOTE]
> GPT 6 Astra Pro was used for the first few runs, with the rest done using 6.1 and 6.2 Sol Medium. I repeat, this is an almost-unmodified LLM port. Assets are copyright Microsoft. To see the readme generated by the LLM, see README_LLM.md.

## Features

* The orginal Inkball, updated for WIndows 10/11 using the latest Windows SDK
* The game is now fully DPI-aware (Per Monitor v2). 
* The game includes a Statistics page with information about the current board, run and lifetime. 
* It is now possible to browse any board and play it directly. 
* The game is significantly smoother on high-DPI displays, and includes an optional FPS counter. 
* It is possible to edit some board properties (such as speed of the chevrons and timer).
* The EXE is self-contained and does not require any additional DLLs.
* x64 but should be easy to compile to x86 and Windows on ARM if needed. 

To run, go to `bin\x64\Release\inkball.exe`.

## Limitations

* This game only runs on Windows, uses the Windows SDK and requires Visual Studio to compile. Ports for other platforms (and possibly older Windows versions) are welcome. 
* The assets themselves are bitmap and hence will look a little blurry. This includes the score counter. 
* There can be minor visual artifacts (eg when the balls are first launched) which do not impede gameplay. 
* There can still be bugs lingering. 
* 100% CPU; DirectDraw for GPU accleration is not used.
