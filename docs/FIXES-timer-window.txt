InkBall timer and window fixes — 8 November 2026

Timed gray walls now use p1 for the open/off duration and p2 for the
closed/on duration. This corrects the five-seconds-off, two-seconds-on
case and updates the board inspector's description.

Checked directly against C:\Program Files\Microsoft Games\inkball\inkball.exe:
the original constructor stores its first duration at +0x6c and second
at +0x70. UpdateObject uses +0x70 while retracted and +0x6c while raised.
The reconstruction had these reversed. The referenced x86 decompilation's
field names/update routine were misleading; the installed x64 EXE was
used as the deciding reference.

Window dragging: the pause handler used to release mouse capture whenever
Windows entered move/resize, cancelling its own native title-bar drag.
Capture is now released only when ending an active ink stroke.

Validation on native Windows / Visual Studio 2026:

  cycles starting both raised and retracted.
- Release catalog: 38 checks passed.
- Release game --smoke-test: exit 0.
- Native capture regression: old code failed on entering move mode;
  fixed code retains capture on move/resize and releases it for ink strokes.

  The same failure was present before either fix; renderer code is unchanged.
